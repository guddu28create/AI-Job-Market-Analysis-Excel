# AI Job Market Analysis Dashboard using Microsoft Excel

## Project Overview

This project presents an interactive AI Job Market Analysis Dashboard developed using Microsoft Excel. The dashboard analyzes 15,000 AI job postings to identify hiring trends, salary distribution, work mode preferences, experience requirements, industry demand, and geographical hiring patterns. It demonstrates the complete data analysis workflow, including data cleaning, profiling, KPI development, visualization, and dashboard creation.

## Objectives

- Analyze AI job market trends using Microsoft Excel.
- Perform data cleaning and profiling.
- Develop meaningful Key Performance Indicators (KPIs).
- Visualize hiring trends using Pivot Charts.
- Build an interactive dashboard using Slicers.
- Generate business insights to support data-driven decision-making.

## Dataset Information

- Dataset: AI Job Market Dataset
- Total Records: 15,000
- Total Columns: 19
- Companies: 16
- Job Titles: 20
- Industries: 15

## Project Workflow

1. Imported the dataset into Microsoft Excel.
2. Converted the dataset into an Excel Table.
3. Performed data cleaning and validation.
4. Checked missing values and duplicate records.
5. Created data profiling metrics.
6. Developed Key Performance Indicators (KPIs).
7. Built Pivot Tables for analysis.
8. Created Pivot Charts.
9. Designed an interactive dashboard.
10. Connected all slicers for dynamic filtering.

## Key Insights

- The dataset contains 15,000 AI job postings across multiple industries and companies.
- The average salary offered is approximately US$115,349.
- AI salaries increase with higher experience requirements.
- Remote, Hybrid, and On-site jobs are distributed relatively evenly.
- AI hiring is concentrated across a limited number of industries.
- Significant salary variation exists among different AI job roles.
